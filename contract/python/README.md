# huaben-tracking-contract

Pydantic models for the backend events in the [tracking contract](../events.yaml). `models.py` and `pyproject.toml` are generated by `scripts/generate_contract.py`; don't edit them.

The app installs this package from a tagged release of this repository:

```toml
[tool.uv.sources]
huaben-tracking-contract = { git = "https://github.com/jack93g/huaben-tracking-platform", subdirectory = "contract/python", tag = "contract-v1.0.0" }
```

```python
from huaben_tracking_contract import Consent, StoryGenerated, StoryGeneratedProperties

event = StoryGenerated(
    event_timestamp=request.completed_at,
    user_id="42",
    consent=Consent(analytics_storage="denied"),
    properties=StoryGeneratedProperties(...),
)
payload = event.model_dump(mode="json")
```

- `event_timestamp` has no default. Pass the time the event happened, e.g. the generation's `completed_at`, not the time it's sent.
- `event_id` is generated when the model is created. Create the model once, and store the payload in the outbox as it is, so that retries reuse the same `event_id` and `event_timestamp`.
